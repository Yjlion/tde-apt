Yjlion TDE apt repository

Extra packages for the Trinity Desktop Environment (R14.1) on Debian 13 (trixie), amd64. You also need the official Trinity repository configured.

Add the repository

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://yjlion.github.io/tde-apt/tde-apt.asc -o /etc/apt/keyrings/yjlion-tde.asc
echo "deb [signed-by=/etc/apt/keyrings/yjlion-tde.asc] https://yjlion.github.io/tde-apt trixie main" \
  | sudo tee /etc/apt/sources.list.d/yjlion-tde.list
sudo apt update

Packages

See the package index, or run apt-cache policy after adding the repository.
